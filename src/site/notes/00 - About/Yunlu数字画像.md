## 五、行为模式摘要（记录一切）

1. **催促进度**：连续"好了吗"2 次 = 等太久 → 直接执行或给结果
2. **全自动期望**：Discord 说话 → agent 全自动（发布/修复/整理）
3. **多 Agent 分工**：Manas 主对话、Alaya 记忆、Soma 知识、Anchor Windows、gbrain 共享知识
4. **修复倾向**：不轻易放弃（穷举方案）；源文件优先（Telegram 原始 > 转换版）
5. **隐私边界**：密码/token 不入热记忆；跨 agent 不改文件
6. **时间敏感**：定时任务避开整点（随机分钟）；凌晨不工作（"太晚了明天再弄"）
